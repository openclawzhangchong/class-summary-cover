# 班级实习材料汇总封面打印工具

一个给班主任 / 实习管理员用的**材料归档封面生成与打印小工具**：选班级 → 自动带出班主任和学籍人数 → 手填几个数字 → 一键打印，出来的就是排版好的 A4 封面，直接盖在一堆实习材料最上面方便翻阅。

提供两种使用方式：

- **网页版**：浏览器直接打开 `summary_cover.html` 即可，零依赖；
- **桌面版（exe）**：用 PyInstaller 打包的单文件程序，双击即用，不需要装 Python。

## 功能特性

- ✅ **班级名册内置联动**：内置 20 个班级（班级 / 班主任 / 学籍人数），下拉选班后自动填充班主任姓名和「班级学籍总人数」
- ✅ **支持自定义班级**：名册之外的班级选「自定义…」手动输入，长班名自动缩小字号防止超宽
- ✅ **全部内容可编辑**：封面上的数字、班主任、日期、备注都可以直接点击修改
- ✅ **备注框**：数据表下方的备注栏，可填材料缺失、补交说明等
- ✅ **日期自动填当天**：打开自动填入当天日期，可手动改
- ✅ **严格单张单面 A4**：打印 CSS 锁定单页高度（296.5mm + `overflow: hidden` + `@page margin: 0`），杜绝溢出第二页，打印时选 A4 / 纵向 / 边距「无」/ 单面即可

## 快速开始

### 网页版

直接双击打开 `summary_cover.html`（推荐 Chrome / Edge），点右上角「🖨 打印」。

### 桌面版 exe

从 [Releases](../../releases) 下载 `班级汇总封面打印.exe`（约 16MB，单文件），双击运行即可。

## 自己打包 exe

```bash
# 1. 安装依赖（需要 Python 3.10+）
pip install pywebview pyinstaller

# 2. 打包单文件 exe（Windows，WebView2 渲染）
pyinstaller --onefile --noconsole --name "班级汇总封面打印" --add-data "summary_cover.html;." cover_app.py

# 产物在 dist/ 目录下
```

## 维护班级名册

名册数据在 `summary_cover.html` 里的 `CLASSES` 数组中，三列依次为：班级、班主任、学籍人数。学生转进转出、班主任调整时直接改这里保存即可（网页版改完刷新生效；exe 需要重新打包或改完按上面命令重新出包）。

```js
const CLASSES = [
  ["24电商01",   "温富英", 44],
  ["24电商02",   "林晓红", 31],
  // ...
];
```

## 注意事项

- ⚠️ 切换班级会重新按名册填充班主任 / 学籍人数，并**清空其余五个手填数字**，请一个班填完打印后再切换下一个
- 打印机对话框中如出现「双面打印」默认项，请手动改回「单面」
- 名册中的人数以名册表为准，个别班级实际不符时可直接在封面上点数字修改
